# Balanced brackets

Read a string of brackets and say whether it is balanced: every opening bracket is closed by a
bracket of the same kind, in the right order.

## Input

- Line 1: a string `s` of the characters `(`, `)`, `[`, `]`, `{`, `}` (1 ≤ |s| ≤ 100000).

## Output

One line: `YES` if `s` is balanced, `NO` otherwise.

## Example

Input

```
([]{})
```

Output

```
YES
```

## Limits

Time limit: 1 second. Memory limit: 256 MB. Compiled with `g++ -std=c++17 -O2`.
